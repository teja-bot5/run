# Run

A simple Chrome Dino-inspired endless runner where you play as the developer.

## Overview

Run is a browser-based endless runner built with HTML, CSS, and JavaScript. Inspired by the Chrome Dino game, it challenges players to avoid obstacles and survive for as long as possible.

## Features

- Endless runner gameplay
- Progressive difficulty
- Keyboard controls
- Lightweight and responsive

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

```bash
git clone https://github.com/teja-bot5/run.git
```

Open `index.html` in your browser.
